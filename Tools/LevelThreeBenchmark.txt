Level 3 local relief visibility comparison -- 2026-11-12

GPU: AMD Radeon RX 7900 XTX; DX12 Shader Model 6.7; source-built O3DE Editor.
VueLiveLink, 1280x720, three matched camera views (lower glancing, lower facing,
upper glancing). 600 GPU timestamp samples per view after method prewarming
and settling. TAA and vsync off. Camera intersections remain Level 1,
validation 6 / retry 4 / tolerance 1, source R32 heights, validation Gather off,
automatic pixel LOD, no relief-distance cap. Only local shadow method and
spiral-light shadow sample count change. Neural confidence is 0.995.

Why fewer neural height queries do not establish a GPU win:
The learned path gathers four probes, constructs features, evaluates a
10 -> 12 -> 1 network and a sigmoid, then often still marches. The existing
marcher can exit on an earlier blocker. Different per-pixel fallback lengths
can also limit the benefit of skipped work within a GPU wave. The measured
neural/Gather difference establishes that these costs outweigh the query
savings here; instruction/register/wave contributions have not been profiled
separately. Gathering the same exact heights is the clear measured win.

On 50,000 independent held-out visibility requests per profile, the default
neural threshold adds respectively 10 / 11 / 18 / 14 false-lit results for
wall / stairs / trim / reveal, with no additional false-shadow results.
This is 53 added false-lit results in 200,000 requests (0.0265%). The baseline
itself misses thin occluders between discrete samples; the reference traverses
the continuous bilinear height surface in a frozen displacement frame. It
does not trace other faces. The stairs model is tested offline; the level's
stairs remain ordinary geometry. Higher confidence increases fallback use.
